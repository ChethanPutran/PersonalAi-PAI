What you can ask PAI

Type or say a goal in plain words. PAI plans the steps and runs them on the right device, which does not have to be the one you are talking to. What is available depends on the plugins installed and enabled, and on which of your devices are online.

Chat and answers

Always available

  • Questions, explanations, advice, rough guesses
  • "What can you do?"
"I'm feeling hot. Can you guess the temperature?"

Reminders and schedules

Built in. The target device must allow remote use.

  • One-time, repeating (every N minutes or hours) and cron schedules
  • Create, list and delete them
  • Check your running and past tasks
"Remind me to call mom at 6pm tomorrow."

Camera

Camera plugin on the phone. Asks every time.

  • Take a photo or record a video
  • Save a copy to the gallery
"Take a photo with the back camera and save it to my gallery."

Location, contacts, device

Plugins on the device

  • Where you are now
  • Search or get a contact
  • Battery, model and other device info
"Where am I?"

Notifications, flashlight, volume, media

Plugins on the device

  • Send a notification to a device
  • Flashlight on or off
  • Set the volume, control playback
"Turn on the flashlight on my phone."

Clipboard

Clipboard plugin

  • Read what is on the clipboard
  • Copy text to it
"Copy this address to my phone's clipboard."

Apps

Apps plugin

  • List, launch and open apps
"Open the calculator on my phone."

Files

Files plugin. Limited to the folders you allowed.

  • List, read, write, copy and move files; check file info
  • Delete files (asks first)
"List the PDFs in my downloads folder on the server."

Browser

Browser plugin on a device

  • Open a page, fill in a form, make a booking
"Open the browser on the server and go to wikipedia.org."

Computer control

Computer control plugin, ready on the device

  • Look at the screen; click, long-press, type, press keys, scroll, swipe
  • List, launch and check the foreground app
  • Ask for its status to see what is missing
"Check if computer control is ready on my phone."

Agents

Turn on the Agent plugin first

  • Start a long-running agent for a multi-step goal
  • Message it, check on it, list your agents, stop it
  • Agents only use what you already have, and approvals still apply
"Start an agent to open Settings on my phone and turn on Bluetooth."

How to talk to an agent

  • Start: "Start an agent called Researcher to find the cheapest flight tomorrow."
  • Talk to it: "Tell agent Researcher to look only at morning flights." Also use this to answer its questions.
  • Check: "How is my agent doing?" or "List my agents."
  • Stop: "Stop the Researcher agent."
  • Default budget is 25 steps, up to 100. An agent can never start other agents.

Good to know

  • Risky actions (camera, keyboard and mouse control, shell commands, deleting files) ask for your approval, and voice can never approve them. Confirm on screen.
  • Each device has its own switches for remote install and remote use, off by default. With remote use off, that device refuses plugin requests from your other devices, including schedules.
  • Scheduled actions that need approval run only after you approve them in Reminders.
  • If something is missing, install and enable its plugin from the Plugins screen or Settings.
